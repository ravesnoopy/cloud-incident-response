# Project Scope and Source Material

## Purpose

Demonstrate practical cloud-security and incident-response reasoning for roles such as Junior Cloud Security Analyst, SOC Analyst, Incident Response Analyst and Junior Security Engineer.

## Sources

| Source | Content | Used for |
|---|---|---|
| Tutor-reviewed workbook (Sprint 11) | Triage, attack chain, containment, decision, post-incident, real-case comparison | `sprint11-incident-context/` |
| Interactive case-lab screenshots | Triage, chain reconstruction, final report | `evidence/` |
| AWS Skill Builder challenges A–F | Task statements (paraphrased) | `aws-response-labs/` |
| Author's drafts and notes | Early written answers and working notes | Cross-checking only |

## Not published

- Instruction, checklist and student-data sheets of the workbook
- The hint log of the case lab
- Verbatim challenge text from the training provider
- Any credential, token or account identifier

## Language

The sources were written in Spanish; this repository is in English. Identifiers (hostnames, account names, alert IDs) are kept as in the source.
