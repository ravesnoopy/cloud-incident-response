# Publication Checklist

## Privacy and confidentiality
- [ ] No account IDs, ARNs, access keys, tokens, emails or IP addresses from a real environment.
- [ ] Screenshots reviewed at full resolution; blur anything sensitive.
- [ ] Hint transcript and its screenshot **not** included.
- [ ] Workbook sheets *Instructions*, *Student data*, *Checklist* **not** included; `*.xlsx` and `*.rtf` are in `.gitignore`.
- [ ] No verbatim challenge text from the training provider.
- [ ] Author name publication confirmed (Leonardo Romero Garcia).

- [ ] Every "Planned" item is still labelled Planned.
- [ ] Simulated vs. real is stated in the root README and each track README.
- [ ] Credential name, type and status match official documentation exactly.
- [ ] Author-to-confirm notes in `03-containment.md` resolved.
- [ ] Public facts in `06-real-case-comparison.md` checked against primary sources.

## Quality
- [ ] All relative links work.
- [ ] Spelling and terminology consistent (MITRE technique IDs, AWS service names).
- [ ] `LICENSE` year and name correct.
- [ ] Repository description and topics set.
